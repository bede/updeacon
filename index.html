updeacon-s3

Locally dehost and upload fasta/fastq file(s) to CLIMB S3 object storage. Runs Deacon using WebAssembly to remove human reads prior to upload. Use the access key ID and secret access key shown in the 'S3 Buckets' area of the CLIMB portal. Use with the panhuman-1 Deacon index (850MB).
